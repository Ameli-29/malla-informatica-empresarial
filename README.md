# Malla curricular interactiva · Informática Empresarial

Página estática hecha con HTML, CSS y JavaScript, pensada para publicarse con GitHub Pages.

## Archivos
- `index.html`: estructura de la página.
- `style.css`: diseño pastel morado adaptable a móvil y computadora.
- `cursos.js`: datos de cursos, créditos, semestre y requisitos.
- `script.js`: interacción, progreso y guardado local.

## Importante sobre los datos
Los cursos y créditos que aparecen son demostrativos y NO constituyen la malla oficial de la UCR. Antes de utilizar el proyecto para planificar matrícula, reemplaza los datos de `cursos.js` con la malla curricular oficial vigente y verifica cada requisito.

## Publicar con GitHub Pages
1. Sube los cuatro archivos a la raíz del repositorio.
2. Abre **Settings → Pages**.
3. En **Build and deployment**, elige **Deploy from a branch**.
4. Selecciona la rama `main` y la carpeta `/(root)`; pulsa **Save**.
5. Espera unos minutos y abre la URL que aparece en la sección Pages.

El avance se guarda en el almacenamiento local del navegador de cada dispositivo. No se sincroniza automáticamente entre dispositivos ni navegadores.
